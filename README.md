🏫 School Management System

Overview

School Management System is a Python-based console application designed to manage student records, academic performance, and report cards. The system allows users to add, update, search, and delete student records, manage subject-wise marks, generate report cards, and store data using JSON files.

Features

- Add new students
- View all students
- Search student records
- Update student information
- Delete student records
- Add subject-wise marks
- Calculate average marks
- Automatic grade calculation
- Generate student report cards
- JSON-based data storage

Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- JSON File Handling

Project Structure

school_management_system.py
school_data.json

How to Run

1. Clone the repository:

git clone <repository-url>

2. Navigate to the project directory:

cd School-Management-System

3. Run the application:

python school_management_system.py

Menu Options

1. Add Student
2. View Students
3. Search Student
4. Update Student
5. Delete Student
6. Add Marks
7. Generate Report Card
8. Statistics
9. Exit
